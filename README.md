# Умами — моя домашняя кухня

Небольшое адаптивное приложение с японскими рецептами на русском языке.

## Возможности

- Рис, мисо-суп, курица терияки, удон с курицей и онигири с тунцом.
- Поиск по названию и ингредиентам, фильтры по категориям.
- Пересчёт ингредиентов для 1–12 порций или штук.
- Пошаговый режим готовки.
- Избранное и список покупок с отметками и копированием.
- Хранение избранного и покупок в localStorage текущего браузера.

## Запуск

Сборка и зависимости не нужны. Из каталога проекта:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Для размещения достаточно любого статического хостинга. Копирование списка требует HTTPS или localhost и разрешения браузера на буфер обмена.

## Файлы

- `index.html` — разметка, адаптивные стили.
- `app.js` — рецепты, иллюстрации SVG и логика интерфейса.

Данные не синхронизируются между устройствами. Сервер и API-ключи не используются.
